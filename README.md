# Nexora Discord Bot

Nexora is an all-in-one Discord management bot.

## Planned Features

- Moderation
- AutoMod
- Anti-spam
- Tickets
- Welcome system
- Logging
- Auto roles
- Giveaways
- XP and levels
- Minecraft server status
- Voice features
- AI system
- Web dashboard
- Separate website

## Tech Stack

- Node.js
- discord.js
- PostgreSQL
- Next.js
- Discord OAuth2

## Development

This project is currently under development.
